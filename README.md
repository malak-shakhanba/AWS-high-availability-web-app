# AWS High Availability Web Application

## Project Overview

This project demonstrates a highly available and scalable web application architecture built on Amazon Web Services (AWS).

The infrastructure uses an Application Load Balancer and an Auto Scaling Group to distribute traffic across multiple EC2 instances in private subnets across multiple Availability Zones.

## AWS Services

- Amazon VPC
- Public and Private Subnets
- Internet Gateway
- NAT Gateway
- Amazon EC2
- Application Load Balancer (ALB)
- Auto Scaling Group
- Amazon CloudWatch

## Project Objectives

- Design a secure AWS network architecture.
- Distribute incoming HTTP traffic across multiple EC2 instances.
- Improve availability across multiple Availability Zones.
- Automatically scale application servers.
- Monitor infrastructure health and performance.
